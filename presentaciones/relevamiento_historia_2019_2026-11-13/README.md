## Alcance

Se revisaron contratos, código y resultados guardados; no se ejecutaron nuevos entrenamientos. V4 y v6 tienen evaluación en octubre; v5 tiene pendiente esa evaluación. Los resultados de Ezequiel no son directamente comparables por calendario, ponderación y definición de ganancia. La presentación distingue las tablas de PAQ_P3 de los parámetros del MAIN actual.

El híbrido es una propuesta: R4 como control, R4 + tendencia T4 y R4 + cambios relativos simétricos, con pesos iguales y presupuesto parejo. No se afirma que sumar variables garantice una mejora. Octubre ya observado se considera exploratorio para las nuevas hipótesis.
